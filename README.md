
# Bitácora

Aplicación web personal para llevar el control de horas de servicio social.

## Funcionalidades iniciales

- Reloj y fecha actual.
- Registro de entrada y salida.
- Validación de una entrada y una salida por día.
- Cálculo de horas por jornada.
- Resumen semanal y acumulado.
- Historial de asistencia.
- Diseño adaptable a celulares y computadoras.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- GitHub Pages (publicación futura)
- Firebase (integración futura)

## Estructura

```text
bitacora/
├── index.html

├── css/
│   └── styles.css
└── js/

```

## Probar localmente

1. Abre la carpeta en Visual Studio Code.
2. Inicia un servidor local.
3. Abre la dirección local en tu navegador.

También puedes usar la extensión Live Server.

## Estado actual

Versión inicial de demostración.

Los registros se mantienen únicamente en memoria y se pierden
al recargar la página o cerrar la pestaña.

Los registros de ejemplo son ficticios.
